# CloudBackup for Windows — Quickstart Guide

Get your encrypted Windows backup running in 5 minutes!

---

## 1. Download & Install
Download `CloudBackup-Setup.exe` from GitHub Releases and run the installer.

## 2. Launch Dashboard
Click the **CloudBackup** icon in your Start Menu or Desktop. Your browser will open to:
```text
http://127.0.0.1:8765
```

## 3. Connect Google Drive
Click **Setup Wizard / Add Remote**, sign in to Google in your browser, and authorize access.

## 4. Select Folders
Add the local folders you want to back up under **Backup Sources** (e.g. `C:\Users\YourName\Documents`).

## 5. Run Backup
Click **Dry Run** to verify, then click **Run Backup** to start your first encrypted backup!
